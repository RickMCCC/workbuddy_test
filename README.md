# WorkBuddy：自然语言生成看板示例

一个纯前端、可直接打开的最佳实践演示。它使用一套虚构的 Q3 项目数据，展示从中文意图到看板筛选的最小闭环。

## 运行

直接用浏览器打开 `index.html`，或在项目目录执行：

```powershell
npx serve .
```

试试这些输入：

- `本周市场团队的工作负载`
- `产品项目完成趋势`
- `有哪些高风险任务？`
- `比较各团队效率`

## 建议的生产架构

1. **指标语义层**：将指标固化为受控定义（名称、公式、粒度、权限、可用维度）。例如完成率应明确为“已完成任务 / 任务总数”，而不是让模型临时解释。
2. **受控意图结构**：模型仅可返回经过 JSON Schema 校验的配置：`timeRange`、`filters`、`metrics`、`groupBy`、`visualization`。不能让模型生成原始 SQL。
3. **查询计划校验**：服务端根据配置映射到参数化查询；检查字段白名单、时间范围、行数上限与数据权限。
4. **可解释输出**：在图表旁显示已理解的意图、数据更新时间、计算口径、筛选条件，并提供项目明细下钻。
5. **歧义与失败策略**：例如“上个月表现”不明确时，应询问是按自然月还是过去 30 天；没有数据时显示原因和替代建议，不臆造结论。

## 示例数据

`data.js` 含 12 个项目、4 个团队和 90 天 Q3 范围内的虚构任务统计。所有人物、日期和指标均为演示用途。

## 下一步接入真实 AI

将 `interpret()` 替换为调用模型的 API，并要求它按固定 schema 返回看板配置；再由后端把该配置安全地映射到你的数据仓库查询。前端仍只负责渲染已验证的数据与配置。
